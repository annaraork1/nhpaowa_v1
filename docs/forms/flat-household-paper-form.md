# NHPAOWA — Flat paper collection (multi-flat A4)

Prefer the printable UI: **`/flat-update/paper`** — choose **4 / 6 / 8 / 10 / 12 per A4** (card blocks) or **12+ table**, set sheet count, then Print.

## Field guide (P1)

| Field | Example / notes | CSV / register |
|-------|-----------------|----------------|
| Tower number | `21031` or `T21031` (full unit code) | `tower` + `flat_number` / `campusFlatId` |
| Occupancy | O / T / V | `occupancy_status` |
| Primary owner name + phone | Required | primary member |
| Secondary owner name + phone | Optional | associate owner |
| Tenant name + phone | If tenant-occupied | tenant member |
| Notes / vehicles / emergency | Optional on paper; full household via Flats or 015 CSV | household |

## Captains

1. Print enough sheets for the tower/floor.
2. Fill tower number on every block; circle Occ O/T/V.
3. Return packs to office → **Flats → CSV import** (or type into Flat owners).

Resident signature line is per block on the card layout; table layout is for bulk chase lists.
