# Quickstart: Flat Owners

1. Login as Superadmin/Secretary → **Flats** nav.
2. Add flat Wing `A`, Number `101`.
3. Add Primary Owner with phone.
4. Search `101` → found.
5. **Template** → fill / **Import CSV** for bulk upsert (flats + household). See `015-flat-household-csv`.
6. **Export CSV** (includes household columns).
7. Duplicate A-101 → 409.
