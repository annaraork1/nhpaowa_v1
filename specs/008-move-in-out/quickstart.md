# Quickstart: Moves

1. Flat A-101 exists.
2. Create MOVE_IN tenant → Approve → **Download PDF** (logo letterhead gate pass for resident/Security).
3. Start → Complete with meters.
4. Flat occupancy becomes TENANT_OCCUPIED.
5. `/moves?date=today` shows the request.
6. Internal shift: origin + destination via typeahead → complete transfers members + APPROVED household.
7. **Details** → progress timeline + upload attachment (ID/agreement) → Security/Resident view same history.
