# Quickstart: Resident Notices

1. As Secretary, open Notices → create title “Vehicle Verification Drive” + body → save draft.
2. Publish → status PUBLISHED → Download PDF → verify association name, title, body, date, issuer.
3. As Resident, open Notices → see only published item → download PDF.
4. As Secretary, Unpublish → resident list empty for that notice; admin still sees UNPUBLISHED + PDF.
5. Staff role cannot create/publish (403).
