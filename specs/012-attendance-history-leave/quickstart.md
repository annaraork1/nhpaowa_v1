# Quickstart: Attendance History & Leave

1. Open Attendance → confirm KPI strip shows Present / On Leave / Absent / Open check-ins for today.
2. Leave tab → Add leave for a staff member covering today → KPIs update (On Leave +1, Absent −1 if they had been absent).
3. History tab → select yesterday–today → row for leave staff shows ON_LEAVE; checked-in staff shows PRESENT with hours.
4. Export payroll CSV → open in Excel; status column matches History.
5. Cancel leave → status returns to PRESENT or ABSENT.
