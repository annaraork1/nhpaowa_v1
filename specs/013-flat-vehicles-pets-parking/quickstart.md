# Quickstart: Flat household register

1. Open **Flats** → **View** on Tower 1 / 101.  
   Expect: parking `B1-101`, vehicle `KA01AB1234`, pet Bruno, emergency contact, access fob.
2. Close View → **Edit** the same flat.  
   Expect: flat form opens and household panel is available; use **Edit household details** if needed.
3. On Vehicles tab, **Edit** the vehicle, change make, **Save vehicle changes**.  
   Open View again — make is updated. Optionally **Upload RC**.
4. Add pet / contact / device as needed; Pending tab for resident submissions.
