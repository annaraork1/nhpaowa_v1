# Quickstart: Stock Management UX

1. Open **Stock Management**.
2. Stock In → see **Needs replenishment**; click **Use** on a low/out item.
3. Type in the item search box to find by SKU/name; confirm context card.
4. Record quantity → recent transactions list updates.
5. Switch to Stock Out → **Ready to issue** shows healthy in-stock items only (not low/out).
6. On **phone / narrow web**: View modal is full-screen; transactions show as cards (table from tablet up). Mobile Stock In/Out: search + attention chips + last 5 moves.
