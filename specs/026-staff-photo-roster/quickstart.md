# Quickstart: Staff Photo Roster

1. Ensure identity + inventory services and web are running.
2. Sign in as Secretary / Superadmin / Security Head (attendance createEdit).
3. Open **Attendance → Roster → Add staff**.
4. Choose a photo (or skip) → Save.
5. Confirm thumbnail on desktop table and mobile card.
6. Tap photo → preview opens (no file picker).
7. Tap camera badge → file picker; replace photo; preview again.
8. Check in still works with photo present.
