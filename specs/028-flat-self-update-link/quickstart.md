# Quickstart: 028 Flat self-update

## P0 seed (ops — before the drive)

1. Download Flats CSV template from Flats page (or `GET /flats/csv-template`).
2. Fill tower, flat number, and any known owner contacts for every unit (builder Excel → CSV).
3. Import CSV (staff). Every flat starts `collectionPhase=SEED`.
4. Spot-check a few units in Flat owners.

## Digital drive

1. Share `/flat-update` or print update-links CSV / notice (also linked on the login screen).
2. Resident: enter **tower number** (e.g. `21031` / `T21031`) → confirm/correct contacts → submit P1.
3. Secretary: **Flat self-updates** → Approve / Reject (pending queue at top).
4. Watch collection summary by tower; chase towers under 70% P1.

## Household (P2)

Not on the public P1 form. Use Flat owners → Edit household, resident household submissions, CSV import (015), or paper captains → CSV.

## Paper path

1. Open `/flat-update/paper` → choose **4 / 6 / 8 / 10 / 12 per A4** or **12+ table**, set sheet count → Print.
2. Captains fill tower number + contacts; office imports via CSV (015) or Flat owners.
